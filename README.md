# Java Programming Practice

A collection of Java programs created while learning and practicing core Java programming concepts.

## Topics Covered

- Print statements and output
- Variables and data types
- Arithmetic calculations
- User input using `Scanner`
- Conditional statements
- Even and odd number checking
- Loops
- Variable-based calculations
- Number swapping
- Basic problem-solving

## Programs

| Program | Concept Practiced |
|---|---|
| Age Calculator | User input, arithmetic operations, and calculations |
| Even Odd | Conditional statements |
| Input Calculation | Taking input using `Scanner` |
| Multiply | Arithmetic operations |
| Printing with Variable | Variables and output |
| Swap Numbers | Swapping values using variables |
| Swap Without Third Variable | Arithmetic-based value swapping |
| Main | Core Java program structure |

## Technologies Used

- Java
- IntelliJ IDEA

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Open any Java file from the 'src' folder.
4. Run the selected Java class.
